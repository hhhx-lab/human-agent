## 3. 什么可学、什么不可学

### 3.1 可 Shadow 调整（动力学参数）

```text
{α, β, γ, λ, θ}  # 积分、衰减、阈值
network_switch_costs
EFE weights (pragmatic/epistemic/bodily/social)
trait plasticity_base
proactive_drive weights
```

流程：

```text
self_read → growth_need
  → plasticity_window open
  → patch_queue candidate (parameter_patch)
  → replay_shadow compare behavior metrics
  → archive receipt if improved
  → else rollback
```

### 3.2 不可自动改（保持）

- 写门语义
- DreamFactGate blocked_writes
- 关系身份卫生
- post-expression blocked terms
- 核心 identity_root

## 4. Voice Kernel 训练（可选 L2）

仅当需要自然语言且不愿依赖远程 LLM：

```text
训练数据:
  (expression_intent_v1, gated_utterance) pairs
  来源: 通过 post-expression gate 的真实对话

模型:
  0.5B–3B 本地指令模型 或 蒸馏模型

训练边界:
  只学表面化，不学 belief/memory 决策
  CoreContinuityGuard 防污染
```

对接 `93_self_training_kernel_growth_protocol` 的 `TrainingRunEnvelope`。
