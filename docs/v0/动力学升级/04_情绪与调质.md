## 3. 情绪动力学链

```text
InteroceptivePredictionError
  → core_affect (VAD continuous)
  → affective_episode (threshold crossing)
  → emotion_regulation (strategy pick)
  → signal_media.diffusion
  → workspace / memory / expression gates
```

### 3.1 连续 Core Affect

```text
valence(t+dt)   = valence(t) + β1*PE_intero + β2*pain_spike - β3*recovery
arousal(t+dt)   = arousal(t) + β4*uncertainty + β5*relationship_tension
dominance(t+dt) = dominance(t) - β6*responsibility_weight - β7*debt
```

`pain_events` 不再用 `len()`，而用 **衰减中的 pain_trace 场**：

```text
pain_field(t) = Σ pain_event.strength * exp(-λ_p * age)
```

### 3.2 Affective Episode

Episode 在 **状态穿越阈值** 时开启/关闭：

```text
enter_episode if arousal > θ_high AND valence < θ_low
episode_kind ∈ {distress, repair_urgency, calm_repair, guarded_dialogue}
```

`emotion_episode.py` 读 vector 历史（`chronnectome` 或本地 buffer），非单点。

### 3.3 Emotion Regulation

```text
if recovery_rate high → strategy = downregulate_arousal
elif repair_drive high → strategy = approach_repair
elif allostatic_load crisis → strategy = suppress_expression
```

### 3.4 Signal Media 扩散

见 [12_神经振荡扩散与Tick引擎.md](./12_神经振荡扩散与Tick引擎.md)。

情绪对调质的注入：

```text
injection_arousal = f(arousal, pain_field)
injection_repair  = f(repair_drive, responsibility_weight)
```
