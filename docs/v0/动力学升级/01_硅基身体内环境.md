| 能力 | schema 现状 | 动力学峰值 | 生物人脑 |
|------|-------------|------------|----------|
| 需要状态 | 字符串枚举 | 连续向量 + 模态分解 | 极高 |

## 4. 动力学方程（离散）

### 4.1 需要模态（四缺口）

```text
resource_deficit  += f(cpu_time, token_budget, dialogue_turn_rate)
evidence_deficit  += f(prediction_error, ambiguity_queue)
relationship_deficit += f(trust_delta_negative, unrepaired_commitments)
maintenance_deficit += f(schema_drift, validator_incidents, memory_conflicts)
```

各 deficit 通过 **不同恢复动作** 下降（理论：不同口渴模态不同神经群）：

| deficit | 恢复动作 |
|---------|----------|
| resource | sleep, idle, 降频 tick |
| evidence | clarify, world_observation |
| relationship | repair speech_act, apology chain |
| maintenance | growth_rehearsal, archive, validator pass |

### 4.2 AllostaticForecast

```text
predicted_load_1h = w·[relationship_deficit, evidence_deficit, sleep_pressure, pain_pressure]
predicted_recovery_window = g(fatigue, debt, last_recovery_age)
```

行动前 `FutureBodyStateSimulation`（AHB031）：

```text
simulate(action_a) -> body_state_vector'
pick action with min predicted_load_1h' + action_cost
```

接入 `active_sampling_plan` / `go_nogo`。

### 4.3 BodyStateDebt

```text
body_state_debt 只增不减，除非:
  - RecoveryEvent(sleep_cycle_complete)
  - RepairCloseout(confirmed)
  - ArchiveConsolidation(success)
```

慢性关系损伤、反复 pain_event、记忆冲突各贡献不同 `debt_channels`。

## 9. 峰值与生物差距

**可达：** 疲惫时话少、高负荷少写入、睡眠压力驱动离线、修复后 debt 下降——**行为层像有身体**。  
**不可达：** 真实内脏传入、激素级联、免疫-神经耦合。

**情绪随身体变** 依赖本模块；峰值 **中**（相对生物极高）。
