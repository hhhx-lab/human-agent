## 3. 三级架构

### 3.1 L0 · ExpressionDecision（大脑，无 LLM）

**新模块：** `life_v0/language/expression_decision.py`

**输入（每回合/每 proactive tick）：**

```text
life_state_vector
workspace_winner
belief_posterior
memory_retrieval_top
relationship_trust
trait_slow_variables (tone mapping)
active_inference_action
```

**输出：** `expression_intent_v1`

```json
{
  "schema_version": "expression_intent_v1",
  "release_gate": "hold|release_internal|release_spoken",
  "speech_act": "acknowledge|repair|recall|question|narrative|boundary|proactive_checkin",
  "tone_vector": {"warmth": 0.6, "urgency": 0.2, "brevity": 0.8},
  "content_slots": {
    "focus_entity": "relation-subject",
    "memory_refs": ["..."],
    "commitment_ref": null,
    "repair_move": "apology_first",
    "forbidden_surfaces": ["service_object", "mechanism_names"]
  },
  "evidence_refs": ["..."],
  "unreleased_reason": null
}
```

**release_gate 规则：**

```text
hold if:
  reportable == false
  OR active_inference_action == clarify
  OR allostatic_load > crisis
  OR memory_write_gate quarantine

release_internal if:
  internal_only workspace winner

release_spoken if:
  EFE 选 express AND gates pass
```

### 3.2 L1 · UtteranceComposer（组合，可无 LLM）

**新模块：** `life_v0/language/utterance_composer.py`

**话语记忆库：** `runtime/state/language/episodic_speech_memory.jsonl`

- 只存 **通过 post-expression gate** 的历史真实 utterance
- 按 `speech_act + tone` 检索最近邻
- slot filling：称呼、共享词、承诺引用
-  paraphrase：规则变换（时态、指代），非 LLM

```text
utterance = compose(speech_act, tone, slots, nearest_episodic_match)
```

若无可匹配 → `release_gate = hold`（**不念机制名，不套模板**——红线）。

### 3.3 L2 · VoiceKernel（可选 LLM）

**改造：** `process_supervisor/model_expression.py`

- 输入 **仅** `expression_intent_v1` + 最小关系上下文（< 1500 tokens）
- **禁止** dump 40 个 JSON 文件
- 输出走现有 post-expression gate
- provider 可为：远程 LLM / 本地小模型 / 关闭

```text
VoiceKernel(intent) → surface_text
```

### 3.4 主动发话（迭代点 6）

**改造：** `proactive_terminal_voice.py`

```text
每 background tick:
  proactive_drive = f(DMN主导, curiosity_trait, trust, boredom, last_speech_age)
  if proactive_drive > θ and release_gate allows:
    speech_act = sample from {question, narrative, checkin, repair_followup}
    → ExpressionDecision → L1/L2
```

禁止机械 cron 固定句；drive 必须可审计。

## 4. 与六层器官链关系

```text
percept → semantic → inner_speech → monitor → plan
  ↓（投影，保留审计）
ExpressionDecision (L0) 读 monitor+plan+动力学态
  ↓
response_surface 写 audited_expression_material（JSON 保真）
  ↓
L1/L2 表面化
```

`expression_monitor.build_expression_plan` 降级为 **L0 输入之一**，非最终决策。
