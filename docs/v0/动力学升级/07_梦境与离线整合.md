## 3. 动力学加厚点

现有 `dream/*` 链保留。升级集中在 **sleep tick 内 engram 操作**。

### 3.1 睡眠触发

```text
enter_sleep_phase when:
  sleep_pressure > θ_sleep
  OR resident_autonomous_activity == sleep
  OR terminal_closed && exit_dream_summary pending
```

### 3.2 NREM Replay（默认）

```text
sample engram subgraph by:
  - high prediction_error residue
  - suppressed_workspace_candidates
  - relationship_deficit nodes
merge compatible nodes → strengthen core tier
conflicting nodes → quarantine or sediment
```

对接 `offline_memory_consolidation.py`、`cortical_memory_transfer.py`。

### 3.3 REM Dream Generation

```text
combine:
  - turn_residue
  - relationship_residue
  - pain_replay
  - web_dream_residue (if enabled)
→ dream_experience_window scenes (structured)
→ NEVER direct fact write
```

### 3.4 Wake Integration

```text
wake_integration 分流:
  allowed → DreamResidue, SelfNarrativePatchCandidate, RepairCommitment, WakeQuestion
  blocked → direct_fact_memory, relationship_overwrite
sleep_pressure -= recovery_quality * κ_sleep
```

### 3.5 与用户退出终端（迭代点 4a）

```text
terminal close
  → exit_dream_consolidation_summary
  → engram: 边缘信息 accessibility↓↓ → sediment
  → 重点信息 salience↑ → core
  → dialogue_memory_summary 作为 cue 种子，非平行仓库
```
