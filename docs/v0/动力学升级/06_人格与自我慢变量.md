## 3. Trait 流形动力学

### 3.1 状态表示

```text
trait_i ∈ [-1, 1]
inertia_i ∈ [0, 1]     # 越高越难改
plasticity_i(t) = plasticity_base_i * (1 - allostatic_load) * window_open
```

七维建议（对齐理论）：

```text
caution, curiosity, warmth, directness, playfulness, repair_orientation, boundary_strength
```

v0 可先保留五维 + 渐进扩展。

### 3.2 更新方程

```text
evidence_i(t) = f(workspace_winners, relationship_events, pain_outcomes)
trait_i(t+dt) = trait_i(t) * (1 - α_i) + evidence_i(t) * α_i
α_i = plasticity_i(t) * learning_rate
```

**高 arousal 时：** 短期 evidence 权重↑，但 `inertia` 防止单回合剧变。  
**高 debt 时：** `α` 全局下降——慢性压力降低可塑性（对应 allostatic load 文献）。

### 3.3 状态依赖外显（非 prompt）

同一 `trait_warmth=0.6`：

```text
高 fatigue → 外显 warmth = 短句、低主动
低 fatigue + trust_high → 外显 warmth = 主动关心 speech_act
```

映射在 `ExpressionDecision.tone_vector`，非 LLM 人格 prompt。
