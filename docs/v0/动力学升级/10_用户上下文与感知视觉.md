## 3. 用户上下文动力学

### 3.1 Context 不是堆叠，是激活窗口

**改造：** `terminal_turn/context_accumulation.py`

```text
context_window = {
  stm_engram_refs: top activated STM nodes,
  workspace_winner_ref,
  unresolved_commitments,
  semantic_focus,
  turn_count_in_session,
  relation_trust,
  life_state_vector_snapshot_ref
}
```

每回合更新；**不**无限 append 全文。

### 3.2 会话转录与 engram

`terminal_session_transcript` 事件流入 `engram_activation_graph` 作为 **可召回节点**，摘要由 reconsolidation 产生，非平行维护。

### 3.3 文件引用

`file_reference_turn.py` 保持文本预览；新增：

```text
ObservationEvent {
  kind: file_text | file_missing | blocked
  content_hash,
  ref_path,
  truth_status: pending → validated/quarantined
}
```

经 `membrane/observation_truth_gate.py` 后进 AILite 似然。

## 5. 视觉 / 多模态管道（动力学峰值：中）

### 5.1 架构

```text
ComputerBody 输入
  → VisualObservationEvent (image path / screenshot / camera)
  → PerceptualEncoder (本地 CLIP / small VLM，可选)
  → visual_embedding + visual_caption_candidate
  → observation_truth_gate
  → engram node (cross_modal_evidence)
  → AILite observation likelihood
```

**新模块建议：**

- `life_v0/perception/visual_encoder.py`
- `life_v0/perception/observation_event.py`
- 扩展 `state_store/cross_modal_evidence.py`

### 5.2 原则

1. 视觉 **不直达** memory fact；经 TruthGate
2. `visual_percept_present` 由真实 encoder 输出决定
3. 无 encoder 时降级为 **低**（现状），不伪造

### 5.3 与「不看图」运行

无视觉输入时，系统纯语言-关系-内环境动力学仍可峰值运行；视觉是 **增效**，非前提。
