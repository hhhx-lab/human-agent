## 3. 核心：WorkspaceCompetition

**落点（修订）：** `life_v0/neural_core/workspace.py` 内函数 `apply_workspace_topk`

### 3.1 候选来源（每 tick / 每回合）

```text
C_candidates =
  prediction_error_events
  + engram_activation_top
  + inner_speech_drives
  + relationship_pressure_spikes
  + body_alarm_signals
  + proactive_voice_candidates
```

### 3.2 显著性评分

```text
salience(c) =
  w_pe   * norm(prediction_error(c))
+ w_aff  * emotional_intensity(c)
+ w_rel  * relationship_salience(c)
+ w_nov  * novelty(c)
+ w_rep  * repair_urgency(c)
- w_load * allostatic_load
```

### 3.3 容量

```text
K = floor(K_max * cognitive_bandwidth * (1 - fatigue_load))
# 典型 K_max = 5; 高疲惫时 K=1
```

`softmax` 或 `winner-take-most`：

```text
winners = top_K(salience)
workspace_frame.workspace_contents = winners
```

### 3.4 广播

```text
broadcast_frame.primary = winners[0]
broadcast_frame.secondary = winners[1] if K>=2 else null
broadcast_frame.suppressed_candidates = rest  # → dream replay pool
```

淘汰候选写入 `runtime/state/consciousness/suppressed_candidate_pool.json`。

### 3.5 可报告性（Reportability Gate）

```text
reportable =
  winners[0].salience > θ_report
  AND cognitive_bandwidth > θ_bw
  AND NOT (allostatic_load > θ_load_crisis)
```

`consciousness_probe_bundle` 读 `reportable` + `confidence`。

### 3.6 元认知

```text
confidence = 1 - norm(prediction_error_primary)
conflict_detected = |belief_a - belief_b| > θ_conflict
metacognition_state = {
  confidence,
  conflict_detected,
  reportable,
  second_order_focus: winners[0].kind
}
```
