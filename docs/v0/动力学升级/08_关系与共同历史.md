## 3. 关系动力学（加厚，非重建）

### 3.1 Trust 连续变量

```text
trust ∈ [0, 1]
trust(t+dt) = trust(t) + γ1*repair_success - γ2*betrayal_event - γ3*ambiguity_unresolved
```

投影到 `relationship_timeline.trust_trajectories`。

### 3.2 关系 Engram 子图

关系事件进入 `engram_activation_graph` 的 **relationship scope** 子图：

```text
节点: shared_experience, commitment, repair, naming_moment
边: co_occurrence, emotional_binding
```

召回时关系子图优先 spreading（关系主体 scope）。

### 3.3 共同语言动力学

```text
shared_term.weight += η_term * co_occurrence_in_workspace_winner
promotion to registry when weight > θ_promote
```

对接 `language/shared_terms.py` 现有晋升逻辑，改为 **权重积分** 非规则计数。

### 3.4 关系阶段

```text
relationship_stage = g(trust, repair_count, co_presence_ticks, commitment_integrity)
```

`continuity_evolution.py` 读连续 trust，非离散跳变表。
