## 3. NetworkAttractorState

**改造：** `neural_core/network_state.py`

### 3.1 吸引子

```text
attractors:
  DMN:     {self_narrative, memory_integrate, dream_drift}
  SAL:     {prediction_error_scan, threat_detect}
  EXEC:    {language_release, task_lock}
  CONFLICT:{belief_conflict, repair_hold}
```

### 3.2 切换动力学

```text
switch_cost(A→B) = base_cost(A,B) + fatigue_load * κ
dominant = argmin_attractor [ free_energy(attractor) + switch_cost(current→attractor) ]
```

记录到 `chronnectome_log`。

### 3.3 与 idle / 主动发话

```text
DMN 主导 → 后台 self_thinking、主动 narrative 发话概率↑
EXEC 主导 → 任务锁定，主动发话↓
SAL 主导 → clarify / world_observation 优先
```

## 4. Active Inference Lite（AILite）

**落点（修订）：** 扩展 `belief_state.py` / `active_sampling.py` / `live_prediction_refresh.py`（无独立 AILite 包）

### 4.1 离散状态空间（v0 可枚举）

**关系 belief：**

```text
{trust_high, trust_medium, trust_low, repair_needed, recalibration}
```

**世界 belief：**

```text
{fact_clear, ambiguous, contradicted, under_observation}
```

**自我 belief：**

```text
{capable, uncertain, overloaded, recovering}
```

联合状态用 **因子图** 或 **小笛卡尔积**（控制 < 200 状态）。

### 4.2 更新

```text
prior = belief(t-1)
likelihood = f(language_percept_features, observation_events)
posterior ∝ prior * likelihood
prediction_error = KL(posterior || prior) 或 log-ratio
belief(t) = posterior
```

`language_percept` 升级：**特征向量**（见 [10](./10_用户上下文与感知视觉.md)），非纯关键词。

### 4.3 Expected Free Energy（动作选择）

```text
actions = {clarify, repair, recall, hold, express, sleep, observe, noop}

EFE(a) = pragmatic_cost(a)
       + epistemic_value(a)      # 降不确定性
       + bodily_cost(a)          # allostatic
       + social_cost(a)          # relationship_deficit

selected = argmin_a EFE(a)
```

输出到 `active_sampling_plan.selected_route` 与 `go_nogo`。

### 4.4 GenerativeWorldModel（离散表）

```text
P(observation | state, action)  # 从 replay 统计估计，非 LLM
P(state' | state, action)       # 慢更新
```

初始 seed 来自 fixture；live 中用 **replay shadow** 更新计数。
