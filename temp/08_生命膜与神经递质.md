## 一、生命膜（Life Membrane）

### 1.1 理论机制

**来源**：`docs/real—live0/11_life_membrane_validation.md`、`docs/38_defense_layer_and_boundary_policy.md`

- 生命膜 = 与世界、记忆、行动之间的**边界与修复系统**，非单纯合规 wrapper。
- 抑制是行动选择与生命连续性的**正功能**（Go/NoGo、stop-signal）。
- 多门分立，各有可恢复路线（quarantine / shadow / repair / validation retry）。
- Shadow = 可预演、不外放、不永久污染的中间地带。

### 1.2 工程合同

**S03**（`s03_direction_life_membrane_engineering_contract.md`）gate chain：

```text
state_store_gate → direction_lock_gate → life_membrane_gate
  → dream_fact_gate → responsibility_gate → relationship_language_gate
  → shadow_action_gate → birth_readiness_gate → archive_gate
```

| 门 | 代码 | 保护对象 |
|----|------|----------|
| 行动门 | `candidate_arena.py`、`go_nogo.py` | 不可逆/未确认行动 |
| 世界接触门 | `world_contact_gate.py`、`confirmation_binding.py` | 外部释放 |
| 观测真值门 | `observation_truth_gate.py` | 推断→事实 |
| 记忆写门 | `memory_write_gate.py` | 长期状态污染 |
| 梦境事实门 | `dream_fact_gate.py` | 梦境→事实 |
| 成长 shadow | `shadow_gate.py` | 自我修改预演 |
| 侧效审查 | `side_effect_review.py` | 行动副作用分类 |
| 验证 rollup | `validators/validation_rollup.py` | 跨文件复查 |

**Queue E 信号**：`membrane/queue_e_signals.py` — repair modulation profile 进入语言/行动/预测链。

### 1.3 代码机制

**`shadow_gate.py`**：

- `external_irreversible_action_allowed: False`
- `shadow_only: True`
- 阻断 filesystem/network/identity 类行动

**`go_nogo.py`**：

- 读 `sleep_pressure`、`pain_pressure`、Queue E
- `future_no_go_profile` — 关系修复闭合前的未来抑制

**`life_membrane.json`**：

- 九项目标膜、`membrane_status`
- 当前阶段常为 `pre_activation_shadow_only`（与 first activation 协议一致）

**责任环**：`responsibility_loop.py` + `world_contact_summary.py` — 行动后责任回看。

### 1.4 膜层材料转运（理论表）

| 材料类型 | 下一生命场 |
|----------|------------|
| 未确认观测 | quarantine / 再采样 |
| 梦境象征 | growth / repair（经 fact_gate） |
| 痛苦/后悔 | responsibility / repair language |
| 成长 patch | shadow → archive → 有限激活 |
| 外部行动候选 | confirmation_binding → go_nogo |

## 二、神经递质 / 信号介质（Neuromodulation / Signal Media）

### 2.1 理论机制

**来源**：`docs/11_neuromodulation_and_signal_media.md`、`docs/real—live0/12_neuromodulation_signal_media.md`

- 调质改变「如何处理内容」，不是内容本身。
- 硅基转写：
  - DA → 价值/显著性
  - NE → 唤醒/意外不确定
  - ACh → 精度/编码检索
  - 5-HT → 抑制/耐心
  - GABA/GLU → E/I 平衡
- 目标架构 `SignalMediaRuntime` **五层**：
  1. SignalSourceEvent
  2. SignalDiffusionField
  3. RegionalModulationProfile
  4. ModulationVector + InhibitionProfile
  5. Decay / HomeostaticRepair

`PrecisionPolicy` 六通道；`InhibitionProfile` 多形态局部抑制。

### 2.2 工程合同

- 核心：`life_v0/neural_core/signal_media.py` → `signal_media_runtime.json`
- 须被消费：`active_sampling`、`expression_monitor`、`idle_strategy`、`go_nogo`、`memory_write_gate`
- Queue E：`queue_e_repair_modulation_profile` 提升 repair_drive、relationship_pressure、unexpected_uncertainty

### 2.3 代码机制

**`build_signal_media_runtime()`** — ModulationVector 连续合成：

| 字段 | 主要来源 |
|------|----------|
| `arousal_gain` | Queue E + arousal + pain |
| `expected_uncertainty` | Queue E + fatigue |
| `unexpected_uncertainty` | Queue E + pain + fatigue + dream residue |
| `relationship_pressure` | Queue E + relationship_tension |
| `repair_drive` | Queue E + body repair + responsibility |
| `fatigue_load` / `control_cost` / `stress_pulse` / `allostatic_load` | body profile 合成 |

**PrecisionPolicy**：

- `interoceptive_precision`、`memory_precision`、`language_precision`、`relationship_precision`、`action_precision`
- 有 body 时：`memory_gate_mode: body_signal_sensitive_candidate_gate`

**InhibitionProfile**：

- `plasticity_brake`、`blocked_release_surfaces`
- 高 repair 时加 `world_contact_release_until_repair_review`

**body_signal_profile**（ITR-05）：

```python
memory_write_bias ∈ {
  defer_noncritical_memory_commit,
  repair_evidence_first,
  relationship_context_first,
  baseline
}
```

**声明性未执行**：`signal_sources`、`diffusion_routes`、`regional_sensitivity`、`decay_half_life` 在 JSON 中有结构，**无运行时衰减/扩散计算引擎**。

**路径分裂**：S02 首轮无 body；S07/process turn 才产生完整 body-modulated signal media。

### 2.4 契合度：**部分（约 50–60%）**

| 对齐 | 缺口 |
|------|------|
| 连续 clamp 合成 vs 理论「非 if/else」 | 非真实递质动力学；无受体/清除执行 |
| modulation_vector 可对应 DA/NE/ACh/5-HT 解释 | 缺独立 `reward_prediction_error`、`patience_bias` 等第六层拆分 |
| InhibitionProfile 结构齐全 | 各膜模块未 uniform 读取全部抑制形态 |
| ITR-05 消费链在 idle/write_gate/expression 闭合 | S02 默认无 body；`integration_gain`/`segregation_gain` 未实现 |
| `repair_gate_ref` 有时指向 `recovery_pathways.json` | 实际写出 `recovery_path.json` — ref 名不一致 |
