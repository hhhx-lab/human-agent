# 04 · 感知与主动预测

---

## 一、理论机制

**来源**：`docs/real—live0/09_prediction_perception_world_contact.md`、`docs/13_agentic_human_research_synthesis.md` §主动预测

核心立场：

- 感知 ≠ 被动输入；生命系统用生成模型**预测**世界、身体、关系，用误差驱动注意、采样、行动、学习。
- 三层分离：**观测**（WorldObservation）≠ **推断**（Belief/Error）≠ **事实写入**（TruthGate/MemoryWriteGate）。
- 内感受、社会预测、世界接触进入**同一**信念/误差/采样链。
- 电脑外周 = 可追责世界接触边缘，非技能栈。

主动推理链：

```text
BeliefStateFrame → GenerativeWorldModel → PredictionErrorField
  → PrecisionPolicy → ExpectedFreeEnergyEstimate
  → EpistemicActionCandidate → ObservationEvent → BeliefRevisionEvent
```

断联恢复亦在该链：`DirectionBeliefStateFrame` → 读 README/方向文档 → `DirectionBeliefRevisionEvent`。

## 三、代码机制

### 3.1 语言感知（Language Percept）

`percept.py` → `build_language_percept_frame()`：

- 输入：`incoming_surface`、`speaker_role`（来自 relation scope）
- **关键词触发**：承诺/修复/梦/情绪（中英）
- 连接：`belief_state_ref`、`active_sampling_plan_ref`、`prediction_focus`
- 歧义标记：`shared_term_unresolved`、`relation_role_mismatch`
- **不消费** body/need_state

**Live 路径**：`process_supervisor/live_language_turn.py` 每关系回合刷新五件套之首。

**Batch 路径**：`language/__init__.py` 仍含固定话语 fixture — 与 live 分裂。

### 3.2 预测链（S02 Neural Core）

```text
network_state → signal_media（首轮无 body）
  → belief_state → prediction_error → active_sampling
  → prediction_workspace → consciousness workspace
```

**`prediction_error.py`**：种子误差（语义歧义、关系 guard、Queue E）；`stage_effect` 由 uncertainty + Queue E `pressure_level` 决定；**无** body/fatigue 专用 error_event。

**`prediction_workspace.py`**：汇聚 language handoff、precision、采样 route、Queue E repair profile — **S06/S07 handoff 枢纽**。

**`belief_state.py` / `active_sampling.py`**：**不直接读** body 状态；身体不确定经 signal_media 间接传递。

### 3.3 世界接触与膜层边缘

**`world_observation.py`**：

- 从 active_sampling、workspace、signal_media 组 `prioritized_channels`
- 默认 `observation_status: shadow_observation_only`

**`periphery_normalizer.py`**：

- 按 fatigue/relationship 权重 promote/suppress/defer 通道
- 合并 `body_pressure` 块

**`world_contact_gate.py` / `observation_truth_gate.py`**：推断→事实边界（见生命膜卷）。

### 3.4 常驻回合中的预测闭合

`live_turn_cycle.py`：

```text
refresh_live_language_turn（percept 等）
  → project_memory_retrieval_from_live_turn
  → project_memory_write_gate_with_signal_body（ITR-05）
  → compose_life_response（含 prediction/responsibility 等审计段）
```

process_supervisor 层（idle/dialogue/response_surface）消费 `body_signal_write_modulation` — **非 S02 build 路径**。

## 五、契合度：**部分**

| 维度 | 评估 |
|------|------|
| 对象链与 playbook | **高** — 命名与写入顺序一致 |
| 观测/推断/事实分离 | **中高** — 合同+validator 有要求 |
| 身体化预测 | **中** — S02 首轮无 body；完整链在 S07+turn |
| 感知深度 | **低中** — 规则/关键词级，非语用解析 |
| percept ↔ core_affect | **低** — 双轨未统一 |

**断链检查**（文档 09）：若 `language_percept_frame` 有 `prediction_focus` 但 `belief_state_frame` 无对应 revision，或 world_observation 永远 `shadow_only` 且无 repair route — 感知链未进入真实世界接触。
