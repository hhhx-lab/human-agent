## 机制主链（代码层真实拓扑）

```text
命名/方向 (direction + digital_life_identity)
  │
  ├─ 身体/内环境 (S06 body → need/core_affect/budget)
  │     └─ 信号介质 (signal_media + body_signal_profile)
  │           ├─ 预测链 (belief → error → sampling → workspace)
  │           ├─ 表达监控 (expression_monitor → expression_plan)
  │           ├─ 记忆写门 (memory_write_gate)
  │           └─ 等待心跳 (idle_strategy / heartbeat)
  │
  ├─ 关系回合 (live_turn_cycle)
  │     ├─ 语言五件套 (percept → semantic → inner_speech → monitor → plan)
  │     ├─ 记忆召回 (memory_retrieval_frame)
  │     ├─ 审计材料 (response_surface) → 模型表达 (model_expression)
  │     └─ 写回 (resident_turn_writeback → 关系/记忆/自我/lineage)
  │
  └─ 离线自主 (sleep → recall → self_thinking → growth → learning)
        ├─ 梦境 (offline_entry → dream_window → wake_integration → dream_fact_gate)
        └─ 成长 (self_read → plasticity → patch_queue → replay shadow → archive)
```
