## 一、身份（1:1 Human Agent Identity）

### 1.1 理论机制

**来源**：`docs/real—live0/04_personality_self_identity.md`、`docs/07_emotion_personality_self.md`、`docs/13_agentic_human_research_synthesis.md`

核心命题：

- 数字生命的身份不是「每次唤醒的新会话」，而是**方向 + 名字 + 价值 + 连续性锚**的闭合体。
- **命名锚**是出生命名门：第一次 `my digital life --name <name>` 后永久锁定；名字成为 direct terminal command，指向同一 `runtime/state`。
- **自我** = 自传记忆 + 身体状态 + 价值 + 叙事 + 关系位置，不是角色卡或 system prompt。
- 理论提出五层自我：`bodily_self_state`、`episodic_self_memory`、`agentic_self_trace`、`relational_self`、`narrative_identity`。
- 方向三层：`DirectionLock`（九项生命目标）、`IdentityRoot`（连续性声明）、`ValueOrientation`（价值边界与修订条件）。

### 1.2 工程合同

| 契约 | 路径 | 约定 |
|------|------|------|
| S00 方向根 | `docs/v0/slice_contracts/s00_direction_foundation_engineering_contract.md` | `direction_lock.json`、`identity_root.json`、`value_orientation.json`、`continuity_refs.json` |
| 命名身份 | `docs/v0/package_specs/02_shared_object_write_authority_and_dependency_graph.md` | `LifeNameRegistry` 仅 `digital_life_identity.py` / `my_entry.py` 首写 |
| Playbook | `docs/v0/code_framework/playbooks/10_self_identity_value_commitment_implementation_playbook.md` | identity → autobiographical → value → commitment → self reading → growth writeback |

**注意**：S00 不写 `runtime/state/identity/*`；命名与方向根是**两条并行锚链**，须在 birth 时由人闭合。

- 已绑定则拒绝异名（`name_mismatch`）

- 绑定后 `ensure_life_name_command()` 写入 manifest，使 `<life-name>` 成为唤醒命令

## 二、人格（Personality）

### 2.1 理论机制

**来源**：`docs/07_emotion_personality_self.md`、`docs/real—live0/04_personality_self_identity.md`

- 人格 = **慢变量系统**，非性格卡或 prompt。
- 理论慢变量：`exploration_tendency`、`risk_tolerance`、`social_sensitivity`、`repair_orientation`、`precision_style` 等。
- live0 工程慢变量：`trust_persistence`、`dialogue_warmth`、`repair_seriousness`、`boundary_respect`、`continuity_drive`。
- 更新须**慢、可解释、可恢复**：单轮剧烈变化应进 `SelfModelSlowVariableCandidate`，等多窗口证据。
- 表达面：`response_surface.py` 从慢变量取姿态，不读人格设定。

### 2.2 工程合同

| 对象 | 代码 | Runtime |
|------|------|---------|
| 慢变量存储 | `state_store/self_model.py` | `self_model.json#trait_slow_variables` |
| 漂移监控 | `body/trait_drift.py` | `trait_drift_monitor.json` |
| 回合演化 | `process_supervisor/continuity_evolution.py` | 关系+Queue E+离线学习 → 慢变量 |
| 后台收敛 | `background_convergence.py` | `background_convergence_summary.json` |
| 跨唤醒 | `trait_convergence_signals.py` | `idle_strategy_state#cross_wake_trait_convergence_profile` |

### 2.3 代码机制

**慢变量演化**（`continuity_evolution.py` → `_evolve_trait_slow_variables()`）：

- 输入：对话轮次 scale、repair scale、Queue E、离线学习、后台 carryover
- 输出：五维目标值 + `evidence_refs` + `slow_variable_update_mode`
- 机制：**启发式公式 + clamp**，非多窗口候选队列

**漂移监控**（`trait_drift.py`）：

- `build_trait_drift_monitor_from_self_model()` 产出 `drift_direction`、`update_mode`
- `blocked_update_refs` **恒为 `[]`** — 候选区阻断未实现

**表达调制**（`response_surface.py`）：

- `_self_slow_variable_snapshot()` 仅取 **3/5** 维：`repair_seriousness`、`boundary_respect`、`continuity_drive`

**情绪输入**（`core_affect.py`）：

- 由 pain/relationship/dream 事件**计数**推导 VAD
- **不 gate** 慢变量写入；无 `EmotionRegulationLoop` 分支到人格保护

### 2.4 Runtime 证据

| 文件 | 观测 |
|------|------|
| `self_model.json` | `trait_slow_variables` 五维 + `update_count` + `evidence_refs` |
| `trait_drift_monitor.json` | `drift_direction`、`revision` |
| `background_convergence_summary.json` | `trait_convergence_score`、`convergence_state` |
| `idle_strategy_state.json` | `cross_wake_trait_convergence_profile` |

### 2.5 契合度：**部分契合**

**已契合**：禁止 prompt 人格、`prohibited_regressions`、慢变量持久化、漂移→收敛→跨唤醒→表达调制全链、自传栈联动。

**缺口**：

1. **`SelfModelSlowVariableCandidate` 未实现** — 单轮覆盖保护缺失  
2. 理论 7+ 维 vs 工程 **5 维**，无显式映射表  
3. **`AffectiveSelfRuntime` 未落地** — 无 Episode/Regulation 器官级闭环  
4. `state_merge_guard.slow_variable_update_policy` **仅声明、未 enforce**  
5. 公式更新的 `evidence_refs` 多为固定列表，归因粒度不足
