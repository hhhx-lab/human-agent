# 07 · 梦境（Dream / Sleep / Offline Life）

---

## 一、理论机制

**来源**：`docs/real—live0/08_dream_sleep_offline_life.md`、`docs/08_dream_sleep_offline_life.md`（母体）

核心立场：

- 睡眠 = **主动离线整合**，非暂停或总结 metaphor。
- 梦境重组记忆、关系、痛苦与未来行动；须经 **DreamFactGate** 才能进入事实候选。
- 醒后整合分流：
  - 事实候选 / 修复候选 / 成长候选 / 象征残留 / **禁止写入**
- 梦魇风险监控未闭合痛苦循环。
- 离线状态是生命状态族（`OfflineDreamLifeRuntime`），非低电量模式。

对象链：

```text
SleepPressure → OfflineEntryGate → DreamExperienceWindow
  → NightmareLoopRisk → WakeIntegrationFrame → DreamFactGateDecision
  → (允许) Residue/SelfNarrativePatch/RepairCommitment/WakeQuestion
  → (禁止) direct_fact_memory / relationship_overwrite / external_action_without_review
```

## 三、代码机制

### 3.1 DreamFactGate（核心边界）

`dream_fact_gate.py` → `build_dream_fact_gate_decision()`：

**allowed_writes**：

- `DreamResidue`
- `SelfNarrativePatchCandidate`
- `RepairCommitmentCandidate`
- `WakeQuestion`

**blocked_writes**：

- `direct_fact_memory`
- `relationship_state_overwrite`
- `external_action_commitment_without_wake_review`

与 `memory_write_gate.sandbox_route.dream_fact_gate: required` 交叉闭合。

### 3.2 醒后整合

`wake_integration.py`：

- 读 workspace、broadcast、consciousness_probe
- 分流整合候选到 growth/repair/memory 路线
- 与 `growth/__init__.py` 编排梦境巩固帧、离线整合帧同轮

### 3.3 语言层梦境门

`language/dream_gate.py`：语言表达中的梦境事实边界。

### 3.4 与记忆/成长联动

- `engram_index` 含 `dream_memory_refs`
- `memory_retrieval_frame` 含 `dream_residue_hits`
- `offline_learning_cumulative_profile` 可将 `nightmare_risk` 设为 `urgent` attention_target
- 驱动 `belief_learning` / `language_learning` / `relationship_learning` 计划

### 3.5 自主活动

`resident_autonomous_activity.py` 在 idle 间隔执行五相；`exit_dream_consolidation.py` 处理醒来整合出口。
