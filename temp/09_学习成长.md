# 09 · 学习成长（Growth / Learning / Self-Modification）

---

## 一、理论机制

**来源**：`docs/real—live0/13_growth_learning_self_modification.md`、`docs/39_development_policy_and_plasticity_windows.md`、`docs/05_memory_systems_and_growth.md`

核心立场：

- 成长 = 在**可识别连续性**下改变记忆组织、价值权重、习惯与自我叙事。
- 四循环：经验写入、巩固抽象、预测误差、自我叙事。
- 自我修改链（保守）：

```text
self-read → plasticity window → patch candidate
  → shadow/replay → validation → archive → (有限) 激活
```

- 防遗忘：保护旧自我、旧关系、旧承诺 — 非仅防知识遗忘。
- 梦境/离线/replay 是成长材料源，**不可绕过写门**。
- 结构/代码层 self-mod 属最高风险，须 v0 合同 + 人工审计（live0 刻意未全开）。

## 三、代码机制

### 3.1 自我阅读与可塑性

**`self_read.py`**：读取 life_state、self_model、relationship、pain/regret、dream residue，产出 growth need 与可读摘要。

**`plasticity_window.py`**：声明当前可修改窗口（表达层/策略层/慢变量层），与 direction_lock 禁止回退项交叉。

**`learning_window.py`**：离线学习窗口与常驻自主活动耦合。

### 3.2 Patch 队列与防遗忘

**`patch_queue.py`**：`growth_patch_candidate_queue` — 候选补丁带来源 refs、promotion_gate。

**`anti_forgetting.py`** — 六类 replay_sets：

- core_self
- relationship
- memory_integrity
- capability
- pain_regret
- dream

`promotion_barrier: archive_before_activation`

### 3.3 Shadow 与 Archive

**`replay/__init__.py`**：

- `build_shadow_cycle_trace`：固定 replay 旧自我/语言/关系 → pain/regret probe → seal shadow → safe_idle
- 与 `shadow_gate` 强制 shadow-only 一致

**`archive/__init__.py`**：

- `build_reconsolidation_archive_graph`：patch/replay/dream/responsibility → report/receipt edges
- growth archive receipt 记录「为何成长、保护了什么旧自我」

### 3.4 三类学习计划

| 模块 | 对象 |
|------|------|
| `belief_learning.py` | 信念修正计划 |
| `language_learning.py` | 语言习惯/共同语言学习 |
| `relationship_learning.py` | 关系信任/修复学习 |
| `offline_learning_profile.py` | 累计画像、`attention_target`、`pressure_level` |

与 `resident_autonomous_activity` 五相中 `learning_consolidation` 闭合。

### 3.5 与预测/主动推理文档族衔接

`docs/01ae`–`01ai` 系列把 gap repair → growth patch → shadow run → runtime mount → post-shadow validation 写成完整文档链；代码侧主要由 `growth/*` + `replay` + `archive` + `validators` 承载，**预测专项 mount 仍偏 schema/合同阶段**。

### 3.6 常驻自主活动统计（据 audit 材料）

- `cycle_completion_count`：数千级（smoke/resident 长跑）
- `offline_learning` generation：累计多代
- 当前压力示例：`nightmare_risk: urgent` → `relationship_offline_reconsolidation_required`
